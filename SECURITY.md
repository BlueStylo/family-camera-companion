# Security and Privacy

The public demo is a local/static simulation. It neither includes nor connects
to real camera endpoints. The optional camera server is an experimental adapter,
not a production-audited surveillance product.

Do not submit device credentials, QR codes, footage, private addresses or family
information in public issues. Use GitHub's private vulnerability reporting when
available under the Security tab. Otherwise open a minimal contact request
without the exploit or any personal data.

Report with synthetic requests and redacted logs. Stop publishing artifacts if
a disclosure is suspected; deleting a later file does not remove Git history.
Rotate exposed credentials before treating a history rewrite as remediation.

No public port forwarding or vendor-cloud bypass is required by this project.
Remote deployment, TLS termination, trusted proxy boundaries, device
compatibility and PTZ stop behavior require a separate, authorized validation.
Do not use this prototype as a safety-critical or emergency monitoring system.
